# RumiCar Arduino Library

Arduino library for controlling RumiCar.

## Installation

### Arduino IDE (manual)

1. Download this repository as a ZIP.
2. In Arduino IDE, go to **Sketch > Include Library > Add .ZIP Library...** and select the ZIP.

### Arduino Library Manager

Not yet available (registration pending).

## Dependencies

- VL53L0X (distance sensor library)

## Supported architectures

`architectures=*` (AVR/ATmega328 class boards and others; the library includes board-specific pin mappings).

## Usage

See `File > Examples > RumiCar > Basic` after installing.
